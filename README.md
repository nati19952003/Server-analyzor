# 🖥 server-stats.sh

A Bash script to analyse server performance at a glance.

## Features
- CPU usage with visual bar + color-coded severity
- Memory (RAM + Swap) breakdown with percentages
- Disk usage across all real mount points
- Top 5 processes by CPU and by Memory
- Network interface RX/TX stats
- Failed SSH login attempts with top attacker IPs

## Usage
```bash
chmod +x server-stats.sh
./server-stats.sh
```
